# Building and Administrating A Microsoft 365 Environment

## Objective
The objective of this project was to build and administer a Microsoft 365 tenant for Contoso Manufacturing while performing realistic administrative task commonly completed by Microsoft 365 Administrators and Windows System Administrators.

The environment was designed to simulate enterprise user management, Exchange Online administration, Microsoft Teams administration, SharePoint Online integration, and collaboration management.

## Why this Project Matters
Modern Windows System Administrators are responsible for much more than Windows Server and Active Directory. 

Organization rely heavily on Microsoft 365 for:
    - Identity Management
    - Email
    - Collaboration
    - File Sharing
    - Communication
    - Department Administration 

This project demonstrates practical experience administering these services in a business environment.

## Environment 

Company: Contoso Manufacturing

Employees: 500

Location: Raleigh & Remote Workforces

## Technologies Used
- Microsoft 365 Admin Center
- Microsoft Entra ID
- Exchange Online
- Microsoft Teams
- SharePoint Online
- Microsoft 365 Groups

## Labs Completed

### Identity Administration
1. Explored Microsoft 365 Admin Center
2. Explored Microsoft Entra ID
3. Created organizational user accounts
4. Created Microsoft 365 Groups
5. Added department users to Microsoft 365 Groups

### Exchange Online
6. Explored Exchange Admin Center
7. Created Shared Mailboxes
8. Created Distribution Lists
9. Configured Automatic Replies
10. Created Mail Flow Rules
11. Performed Message Traces

### Microsoft Teams
12. Created Microsoft Teams & Connected Teams to Microsoft 365 Groups
13. Managed Team Membership & Configured Team Owners

### SharePoint Online
14. Accessed SharePoint through Microsoft Teams, Explored the SharePoint Library, and Verified Teams and SharePoint integration.

## Key Concepts Learned 
During this project, I developed an understanding of how Microsoft 365 services work together to provide enterprise collaboration.

- Microsoft Entra ID provides Identity management
- Microsoft 365 Groups provide shared resources for departments
- Microsoft Teams extends Microsoft 365 Groups with collaboration features.
- SharePoint Online stores file shared within Teams
- Exchange Online manages organizational email and mail flow.

## Conclusion
This project demonstrates hands-on experience administering a Microsoft 365 environment in an enterprise scenario.

This completed labs simulate common administrative requests including user onboarding, group administrations, Exchange Online configuration, Microsoft Teams management, and SharePoint integration. These skills closely align with the daily responsibilities of Help Desk Technicians, IT Support Specialists, Junior System Administrators, Windows System Administrators, and Microsoft 365 Administrators.
