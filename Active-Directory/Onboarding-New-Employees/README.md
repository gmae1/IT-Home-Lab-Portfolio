# Onboarding New Employees Lab

## Objective
Create enterprise Active Directory user accounts, organize them into the specfic department Organizational Unit, populate business related properties, and assign users to the appropriate Global Security Groups.

## Why This Lab Matters
Users provisioning is a core responsibility of IT administrators. Properly creating, organizing, and securing user accounts ensures employees receive the correct access while maintaining consistency and security across the Active Directory environment.

## Steps Performed
- Created five Active Directory user accounts for new employees.
- Placed each user in the correct Organizational Unit
- Configured users attributes including office, department, job title, and company.
- Assigned ttemporary passwords with a mandatory password change upon first logon.
- Added each employee to the appropriate department Global Security Group
- Verified Organizational Unit placement, account properties, and group memeberships.
