# Account Lockout Investigation And Password Reset Lab

## Objective 
Simulate a real world Help Desk account lockout incident by configuring an Account Lockout Policy, investigation a locked account, restoring access, and documenting the resolution

## Why This Lab Matters
Account lockouts and password resets are among the most common support requests in enterprise environments. This lab demonstrates troubleshooting, security policy implementation, and user account recovery using Active Directory.

## Steps Performed
- Configured an Account Lockout Policy through Group Policy
- Forced an account lockout using failed login attempts
- Investigated the users account
- Unlocked the account
- Reset the password
- Verified successful login and reqiured a password change.
- Completed a service desk ticket documenting the incident.
